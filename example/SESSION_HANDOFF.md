## ПОВЕДЕНИЕ ВРАГОВ / БОЙ (`build/scripts/enemyAI.js`)
- Машина состояний `enemy.state` (ENEMY_STATE): IDLE / PATROL_LOOP / PATROL_WANDER /
  CHASE / ATTACK / STUN / DOWN(Мумия). Мёртвый — `type:"corpse"`.
- Контур enemyTick: DOWN-таймер → тень → ярость → иммунитет стана → STUN/ATTACK →
  триггер тени → обнаружение (`enemyNoticeHero`, emo1.png) → `enemyTryAttack` →
  рывок (dashTryTrigger) → chaseStep/stepAlongPath.
- **Клетка врага — ЦЕНТР rect (x+16, y+25)**; спавн со сдвигом −19px по Y.
  Достижимо = flow-field BFS по `matrixLevel===1` (кэш на смену клетки героя);
  путь пуст → враг НЕ переходит в CHASE («бить сквозь стены» невозможно).
- **V18 путь прежде всего**: стоя-бить → best-step в позицию удара → flow-field через
  весь этаж; пересчёт только при смене клетки героя/окончании пути; проверка атаки —
  каждый тик. `aimMiss`/`attackZones` — позиция удара (дальнобойные с дистанции,
  мили вплотную <40px).
- **Честный прицел `enemyAim`**: атака только из CHASE и только если зона кадра
  реально пересекает героя.
- **Ярость (`stats.rage`)**: rage/2 сек каждые rage сек: RAGE_FILTER + speed×1.5
  (анимации ×1.5 через `animInterval` в ОБЕИХ точках сброса счётчика).
- **Тень (`stats.shadow`, Тёмный воин)**: нырок через лужу под ногами (строго по нижней
  кромке кадра), SKIP если герой ближе 2 клеток.
- **Стан**: длится ровно анимацию others[0]; `noStunTime` — ИММУНИТЕТ после стана.
  `enemyChase` НЕ трогает STUN (countDamage станит и тут же notice — иначе анимация
  урона не играет); checkEndAnim сначала снимает STUN. `enemyDie` — единая точка смерти
  (killedEnemes++, library, bossesSlain для boss, дропы, опыт, хуки квестов);
  `reanimateCheck` → DOWN; `reviveEnemy` — 50% hp. НЕ возвращать «стан = noStunTime».
- **Мирные NPC-враги** (волк/культист/Огнементаль): флаг (cultNpc/flameNpc) + перехват
  в НАЧАЛЕ enemyTick глушит штатный ИИ; бой = сброс флага + noticed/called=1.
  Мирный Огнементаль: `flameNpc===1` — не таргетится атаками/скиллами/сплэшем/волком;
  `flameQuestMob===1` (постоянный) — ловушки на него не действуют.
- **Ловушки (V63, trapsFx.js)**: бьют героя и обычных врагов (не боссов); шипы только
  в активной фазе, огонь в обеих, кислотная выпускает облако по наступанию;
  «Великий вор» ×6 — урон врагам ×2.

## ЛОВУШКИ (свод; кодинг + харнесс)
Кодинг:
- Потеря импорта `text`/`image` из svg.js при чистках ломала игру МОЛЧА (V89a/V91:
  падал changeHP → не играла музыка, висели слушатели комикса). Перескан unused
  переудаления НЕ ловит — после массовых чисток гнать call-site сканер.
- `node --check` НЕ ловит ошибки линковки ES-модуля — после правки экспортов линк-чек
  (см. КАК ПРОВЕРЯТЬ); линк-чек с глотающим .catch = ложный ОК.
- stop-подобные флаги (stop=1, attacking, luckyRun, pathTarget) обязаны сниматься во
  ВСЕХ ветках, где сущность должна двигаться (V105/V107: волк замирал навсегда).
- `undefined < N` = false — новые счётчики на сущности инициализировать при спавне.
- Позиция героя каждый тик выводится из спрайта (posAfter=rectPos) — телепорт в тестах
  ТОЛЬКО `spritePos(hero.obj.img, x, y)`; запись в hero.x/y перезаписывается; герой вне
  пола ломает flow-field (петы/враги перестают ходить).
- id спрайтов суффиксится «I» (svg.image) — точные сравнения id ломаются, фильтровать
  по href; circle() игнорирует obj.id; svg.rect пишет id ДОСЛОВНО.
- Однокадровым спрайтам НЕ ставить frame (уводит окно кадра за картинку).
- replace_all в Edit: уникальность фрагмента проверять заранее (урок V83a).
- Кулдауны боссов data-driven: секунды в data.js stats (`spore: 15`), код = `сек*1000/16`;
  описания врагов дублируют числа — обновлять вместе.
- Сметы спрайтшитов: img href — ЛОГИЧЕСКИЙ путь полосы (ключ SHEETS), не физический
  файл; физически всё режется из одного листа `images/sheets/<name>_64.png`.
- data.js: новые записи врагов — в КОНЕЦ группы; enemes.length (число групп) не менять
  (openRoom считает iE+6*levelFloor); парсить data.js регэкспом по `}],` НЕЛЬЗЯ (живёт
  внутри групп) — только структурный импорт.
- Pillow ≥12: ImageMath.eval удалён (unpremultiply — питоньим циклом по мелкому кадру).
Харнесс (headless Chrome):
- СЕТЬ: `Network.setCacheDisabled(true)` ДО навигации (+ reload ignoreCache) — иначе
